# 本地数据库版（feature/local-db）

从 `master`（Supabase 网络数据库版）分出的本地化分支：**SQLite 本地数据库 + 自研极简 Auth + REST API 层**，定位为**单机自托管**部署。

## 运行方式

```bash
pnpm install
# 可选：配置 AI 模型（默认 deepseek-v4-flash）
# .env.local: DEEPSEEK_API_KEY=sk-xxx

pnpm dev          # 启动开发服务器（首个请求自动建库 data/lotion.db）
# 或
pnpm build && pnpm start   # 生产模式（单机自托管）
```

- 数据库文件：`data/lotion.db`（WAL 模式；可用 `LOTION_DB_PATH` 覆盖路径）
- 上传图片：`data/uploads/`（可用 `UPLOAD_DIR` 覆盖）
- **每次启动自动执行迁移**（`lib/local/migrations.ts` 内嵌 DDL + `_migrations` 记录表），无需手动跑 SQL

## 架构

```
浏览器组件 ──fetch──► REST API（app/api/*）──直查──► lib/local/db.ts ──► SQLite (better-sqlite3)
                                      ▲
lib/db.ts 环境分派：server 直查本地层 / client fetch REST（20 个函数签名不变）
Auth：scrypt 密码哈希 + sessions 表 + HttpOnly cookie（lib/local/auth.ts）
路由守卫：(main)/layout.tsx 服务端校验会话（middleware 已删除，规避 Edge 加载原生模块）
Agent/7 工具/压缩链路：直接接收 SQLite 连接（无 Supabase 依赖）
```

## 与 Supabase 版的差异（技术要点）

- **RLS 移除**：安全边界在应用层——本地层所有查询显式带 `userId`；REST 路由统一走 `userFromRequest` 鉴权
- **UUID**：`gen_random_uuid()` → 应用层 `crypto.randomUUID()`（`lib/local/sqlite.ts` 的 `newId()`）
- **时间戳**：TIMESTAMPTZ → TEXT(ISO 8601)；`updatedAt` 由应用层显式更新（无 PG 触发器）
- **BOOLEAN**：INTEGER(0/1)，本地层读写时映射
- **幂等**：`chat_messages(userId, requestId)` 部分唯一索引语义不变，冲突码 `23505` → `SQLITE_CONSTRAINT_UNIQUE`
- **搜索**：`ilike` → SQLite `LIKE ... ESCAPE '\'`（ASCII 大小写不敏感）
- **公开预览**：新增 `GET /api/public/documents/[documentId]`（无鉴权，仅 isPublished）
