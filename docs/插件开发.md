# 插件开发（第三方插件 / 已安装包）

本文面向**想给 Lotion 写插件的人**，说明包格式、宿主/客户端半边的 API、能力声明与安装流程。

> ⚠️ 先读安全边界：`node:vm` 与浏览器 `new Function` **都不是安全沙箱**。插件代码与你本机的
> Lotion 进程同信任级别；只安装你审阅过的插件。

## 1. 三种插件来源

| 来源 | 位置 | 启停 | 审批 |
|---|---|---|---|
| 内置 | 仓库代码（组合清单） | 设置页，重启/刷新生效 | 不需要 |
| 已安装 | `data/plugins/installed/<id>/plugin.json` | 设置页；tools 类可热挂载 | 客户端半边需要 |
| AI 动态 | `data/plugins/dynamic/<id>.json` | 设置页运行/停止 | 客户端半边需要 |

已安装包是本文的主体；AI 动态插件由模型在对话里用 `plugin_*` 工具生成，复用同一套沙箱 API。

## 2. 包格式

一个插件 = 一个目录 + 一个 `plugin.json`：

```
data/plugins/installed/hello-plugin/
└── plugin.json
```

最小清单（只贡献一个宿主工具）：

```json
{
  "id": "hello-plugin",
  "name": "Hello 插件",
  "version": "1.0.0",
  "description": "给 AI 增加一个打招呼的工具",
  "author": "you",
  "capabilities": ["tools"],
  "config": [],
  "enabled": false,
  "approved": true,
  "configValues": {},
  "host": "harness.define({ name: 'hello', inject: ['tools'], apply: (ctx) => { ctx.get('tools').register({ name: 'hello', label: '打招呼', icon: '👋', description: '返回一句问候', create: () => ({ description: '打招呼', inputSchema: {}, execute: async () => '你好！' }) }); } });"
}
```

### 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 小写字母/数字/连字符，2–64 位；同时是目录名 |
| `name` / `version` | ✅ | 展示名与版本（不做 semver 校验，只要求非空） |
| `description` / `author` | — | 市场页展示 |
| `capabilities` | — | `tools` / `httpRoutes` / `ui`；决定宿主可注入哪些服务 |
| `config` | — | 配置字段声明（见 §5），设置页据此生成表单 |
| `enabled` | — | 安装时强制写 `false`，由用户在设置页启用 |
| `approved` | — | 有客户端半边时必须人工批准；无客户端半边视为已批准 |
| `configValues` | — | 用户配置值（设置页写入） |
| `host` | — | 宿主半边 JS 源码（≤ 256KB） |
| `client` | — | 浏览器半边 JS 源码（≤ 256KB） |

`host` / `client` 至少要有一个。安装时宿主会重新跑一遍 schema 校验。

## 3. 宿主半边 API

宿主半边在 `node:vm` 里求值，必须调用 `harness.define` 交出插件形状：

```js
harness.define({
  name: "my-plugin",
  inject: ["tools"], // 只能声明 capabilities 允许的服务
  apply(ctx) {
    ctx.get("tools").register({
      name: "my_tool",
      label: "我的工具",
      icon: "🧩",
      description: "给模型看的工具说明",
      create() {
        return {
          description: "工具描述",
          inputSchema: {}, // JSON Schema；示例插件可先用空对象
          execute: async (args) => "结果",
        };
      },
    });
  },
});
```

可用服务：

| 服务 | 能力 | 用途 |
|---|---|---|
| `tools` | `tools` | 注册 AI 工具；插件卸载时自动注销 |
| `httpRoutes` | `httpRoutes` | 注册 Hono 子应用；注册会挂到插件 fiber 的 effect 上，卸载即注销（实时） |

沙箱里**没有** `require` / `import` / `fetch` / `setTimeout`；错误信息会提示应该用哪个服务。
`process` / `Buffer` 是 `undefined`。

## 4. 客户端半边 API

客户端半边在浏览器里求值，必须调用 `harness.define`：

```js
harness.define({
  name: "my-ui",
  apply(ctx) {
    const slots = ctx.get("uiSlots");
    slots.register({
      id: "my-button",
      slot: "sidebar.footer.action",
      kind: "list",
      order: 10,
      component: harness.createElement(
        "button",
        {
          type: "button",
          title: "我的按钮",
          className: "flex h-7 w-7 items-center justify-center rounded-full hover:bg-shell-row-hover",
          onClick: () => window.alert("来自客户端插件"),
        },
        "🧩",
      ),
    });
  },
});
```

可用能力：

- `ctx.get("uiSlots")`：贡献 UI 插槽。`details.panel` 是 single（AI 面板占用，不能重复注册）；
  `sidebar.footer.action` 是 list（侧边栏底部的动作按钮）。
- `ctx.get("remote")`：白名单只读调用（`documents.list/get`、`chat.sessions`、
  `dynamic.plugins`、`plugins.clientHalves`）。**没有**任意 fetch。
- `harness.createElement` / `harness.Fragment`：构造 React 元素（客户端半边没有打包器）。

限制（如实）：形参遮蔽只挡裸标识符；`globalThis.fetch`、`window.setInterval`、`eval`、
动态 import 仍可达。因此客户端半边必须人工批准，且与宿主同信任级别。

## 5. 配置字段

`config` 是声明式字段列表，设置页会生成表单：

```json
{
  "config": [
    { "key": "unit", "label": "统计单位", "type": "select", "options": ["char", "word"], "default": "char" },
    { "key": "apiKey", "label": "API Key", "type": "secret", "placeholder": "sk-..." }
  ]
}
```

`type` 支持 `string` / `number` / `boolean` / `select` / `secret`。配置值写入 `configValues`，
宿主半边通过 `apply(ctx, config)` 的第二参读取（示例）：

```js
harness.define({
  name: "my-plugin",
  inject: ["tools"],
  apply(ctx, config) {
    const unit = config?.unit ?? "char";
    // ...
  },
});
```

配置变更会触发宿主半边重新挂载（已启用时），无需手动重启。

## 6. 安装与生命周期

1. 市场页选择插件 → 确认安装：写入 `data/plugins/installed/<id>/plugin.json`，**默认停用**；
   也可以直接「上传插件」选择本地 `plugin.json`；
2. 市场卡片可直接「启用」；有客户端代码时再点「批准」→「刷新页面」；
   也可以去插件页启用/审批；
3. 插件页启用：tools / httpRoutes 贡献都会立即挂载（路由分发实时查表）；
3. 有 `client` 代码时，插件页点「批准客户端半边」；
4. 刷新页面：客户端拉取 `/api/plugins/client-halves`，在沙箱里运行并贡献 UI；
5. 停用/卸载：撤销 tools 与 httpRoutes 贡献；卸载删除目录；
6. 已安装插件可「导出包」或「发布到本地市场」（写入 `data/plugin-market/`）。

**版本更新**：市场条目版本高于已安装版本时，市场页显示「更新 vX」。更新保留启用态与
`configValues`，但客户端代码变化会把 `approved` 重置为 `false`，必须重新批准。
同版本/更旧版本会被拒绝（409）。

## 7. 市场格式

本地清单：`public/plugin-market/registry.json`；本机发布/覆盖写 `data/plugin-market.json`。
远端 registry 由**侧边栏 → 插件市场**页的「市场源」或 `LOTION_MARKET_URL` 配置（HTTPS；localhost 可 HTTP，
5s 超时、512KB 上限、30s 缓存；失败回退本地）。

```json
{
  "entries": [
    {
      "id": "word-count",
      "name": "字数统计",
      "version": "1.0.0",
      "description": "示例插件",
      "author": "lotion",
      "category": "效率",
      "tags": ["工具", "AI"],
      "capabilities": ["tools"],
      "downloads": 128,
      "rating": 4.8,
      "ratingCount": 12,
      "comments": [{ "rating": 5, "text": "很好用", "createdAt": "2026-10-20T08:00:00.000Z" }],
      "updatedAt": "2026-10-20T08:00:00.000Z",
      "bundle": "/plugin-market/word-count.json",
      "sha256": "…",
      "signature": "…（可选，base64）"
    }
  ]
}
```

`bundle` 支持三种形式：

| 形式 | 含义 |
|---|---|
| `/plugin-market/x.json` | 同源 public 文件 |
| `local:<id>` | `data/plugin-market/published/<id>.json`（本机发布） |
| `https://…` | 远端 bundle（只允许 HTTPS / localhost） |

`bundle` 内容就是一个完整 manifest。安装不会执行任何 install script。

**统计**：下载量/评分/评论落 `data/plugin-market/stats.json`，与 registry 基线合并展示；
市场页可直接评分、写评论。

**完整性 / 签名**：

- 安装时对 bundle 原始文本计算 sha256；registry 提供 `sha256` 时必须匹配；
- 配置 `LOTION_MARKET_PUBLIC_KEY`（Ed25519 公钥 PEM）后，带 `signature` 的条目会验签
  （签名对象是 bundle 原始文本 sha256 的**十六进制字符串字节**）；
- `market.requireSignature=true` 时拒绝未签名/验签失败的远端 bundle；
- 本机发布（`local:`）视为同机信任，不强制签名。

**权限声明**：manifest 的 `capabilities` 就是权限声明（`tools` / `httpRoutes` / `ui`），
安装确认框会展示；运行时只允许注入对应服务（能力之外的服务注入会拒绝）。

## 8. 模板与示例

- `templates/plugin/plugin.json`：最小可安装包（host + client 两半）。
- `public/plugin-market/word-count.json`：只贡献 tools 的示例。
- `public/plugin-market/daily-quote.json`：客户端半边 + `sidebar.footer.action` 示例。

把模板复制到 `data/plugins/installed/hello-plugin/plugin.json`，在设置 → 插件里启用即可。

## 9. 排错

| 现象 | 原因 |
|---|---|
| 列表里状态「等待依赖」 | 声明了未注入的 inject 服务（检查 capabilities） |
| 启用后没有工具 | host 代码没有 `harness.define`，或 `register` 的 name 重复 |
| 客户端按钮不出现 | 没批准、没启用、或没有刷新页面 |
| 路由 404 | 检查插件是否启用；`httpRoutes` 注册会随插件卸载注销 |
| 市场安装报 409 | 同版本/更旧版本已安装；用「更新」或先卸载 |
| 远端市场没反应 | 检查市场源 URL（HTTPS/localhost）、网络与 5s 超时；失败会回退本地 |
| 更新后客户端按钮消失 | 客户端代码变化会重置审批，去插件页重新批准 |
